| SGR extended | 38/48 truecolor+256, 58/59, 4:x underlines | ◐ | corpus/sgr/extended.case | T17: all **four** spellings xterm accepts — legacy `38;2;R;G;B`, ITU/xterm `38:2:Pi:R:G:B` (Pi ignored, empty Pi included), Pi-less `38:2:R:G:B`, and the mixed `38;2:1:2:3` / `38;5:1` that xterm names in `charproc.c` — told apart by subparameter count (`>=5` after the introducer, or xterm's `have>3` off the kind, means Pi is present; trailing ITU tolerance params are consumed and ignored). An unknown color kind consumes the kind as well as the introducer, matching xterm — otherwise `38;7;…` would execute the 7 as reverse video. Subparameters on a code that does not take them are ignored, not acted on (xterm `op=9999`), which is also what disarms a leading `CSI :3 m` from firing SGR 0. 58/59 set/reset underline color; `ul` Kind::Default means "follow fg" (kitty: a SET underline color must survive reverse video — that half is a RENDERER obligation and is NOT implemented). 4:0-4:5 styles, clamped above 5 per kitty's `MIN(5,n)`. Out-of-range channels/indices (>255) change nothing but still consume their arguments — this matches **xterm**; kitty instead truncates mod 256, so the two references disagree and neither clamps. SGR 21 = doubly-underlined per xterm/ECMA-48 and kitty (some other terminals read 21 as bold-off; kitty puts that at private code 221). The spike renderer paints only the classic 16 and leaves 256-index/truecolor/underline at the default until T25 |
| Erase/scroll | ED EL IL DL SU SD DECSTBM | ◐ | corpus/sgr/{erase,scroll}.case | T7: ED 0/1/2 + EL 0/1/2 (ED3 no-op until real grid; BCE undecided; DECSED/DECSEL rejected). T18: DECSTBM + IL/DL/SU/SD. DECSTBM clamps Pt<1→1 and Pb omitted/0/oversize→page height, THEN ignores an inverted or degenerate region entirely (xterm's `if (bot > top)` has no else — margins and cursor both keep their values); DEC STD 070 is stricter still, also ignoring an oversize Pb, and we deliberately take xterm's clamp for app compat. Cursor homes on a successful DECSTBM. IL/DL are no-ops outside the region and move the cursor to the left margin (xterm/VTE do; konsole, urxvt and the linux console do NOT — divergence is deliberate). SU/SD have no in-region gate and never touch the cursor. `CSI Ps T` is SD only with exactly one non-zero parameter, so `CSI 0 T` is not SD and the 2–4 parameter arities are consumed and ignored rather than guessed. Scrollback capture is gated on the TOP margin alone (xterm's `top_marg == 0`), not on a full-screen region. MISSING: left/right margins (DECSLRM / mode 69) are not implemented, so IL/DL/SU/SD are full-width — conformant only because mode 69 is never answered as set. **Origin mode (DECOM) and alt screen 1049 are still ✗** — both need a DECSET/DECRST seam that does not exist yet |
