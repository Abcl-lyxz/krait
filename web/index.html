Krait

A modern terminal and SSH client for Windows. Everything PuTTY does, none of what it got stuck on.

Krait is not released yet. There is no download on this page because there is no signed build to download. This page describes what is being built and links to the source.

What it is

  • One app for every connection — SSH, local shells over ConPTY, telnet, raw sockets and serial, in tabs, with saved sessions that are a real part of the product rather than a dialog you dread.
  • GPU rendering — a custom glyph atlas and damage tracking, built to hold 60 fps under a cat flood.
  • Thai, CJK and emoji as first-class text — grapheme clustering and real shaping, not a wcwidth guess. Thai ships as a first-class locale, not an afterthought.
  • Sixel and kitty graphics — images in the terminal, anchored to the text they belong to so they survive scrolling and rewrapping.
  • Security UX that guides — host keys, a paste guard, and red accents on production sessions. Secrets live only in the Windows DPAPI vault, never in a config file.

Building it

cmake --preset dev
cmake --build --preset dev
ctest --preset dev

You need Visual Studio with the x64 C++ toolset, Qt 6, and a vcpkg checkout. SETUP.md has the exact versions and the reasons behind them.

Design notes

Decisions are written down as ADRs rather than lost in commit messages, and the terminal's escape-sequence support is tracked honestly — including what is not implemented — in a conformance ledger.
